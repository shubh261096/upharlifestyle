# Stock image credits

All images in this folder are from **Pexels** and used under the
[Pexels License](https://www.pexels.com/license/), which permits free
commercial use with no attribution required. Attribution is recorded here
anyway, as good practice and as proof of provenance if the source of an image
is ever queried.

## Selection rules applied

Every file was downloaded and **visually checked** before use. An image was
only kept if it passed all four tests:

1. **No visible faces.** Only garments, hangers, rails, flat lays, accessories
   and detail shots. Some images show hands or a torso; none show a face.
2. **No legible third-party garment brand labels** — a readable brand label
   implies the shop stocks that brand.
3. **Genuinely relevant** to menswear, groom wear or tailoring.
4. **Not another party's personal material** (e.g. a real couple's named
   wedding invitation).
